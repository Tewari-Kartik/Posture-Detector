# 🧘 Posture Detector

**An AI-powered web application that monitors and alerts you to maintain a healthy posture in real-time using Computer Vision.**

## 🔗 Live Demo
🚀 **[Launch Posture Detector](https://tewari-kartik.github.io/Posture-Detector/)**

---

## 🌟 Overview
Maintaining good posture is crucial for long-term health, especially for those spending long hours in front of a screen. This project utilizes machine learning to detect body alignment through a webcam and provides immediate visual feedback.

### Key Features:
* **Real-time Detection:** High-speed pose estimation directly in the browser.
* **Visual Feedback:** Live overlay of skeletal landmarks to show alignment.
* **Privacy Focused:** All processing is done locally; no video data is ever sent to a server.
* **Minimalist UI:** Clean and responsive interface for seamless use.
